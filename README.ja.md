## どんなアプリか

瞬間ジャーナルは「日記を書くこと」の邪魔をできるだけしません：

- **書くときに迷わない。** 起動するとそのまま編集画面です。間に挟まる画面はありません。
- **消える心配がない。** 入力が止まると保存され、画面を離れるときにもう一度保存されます。
- **データはあなたの手元に。** 日記は端末の中だけに保存され、バックアップは自分で選んだフォルダに入ります。

## 機能

### 書く

- **タイトルと本文。** 本文は Markdown に対応：太字、斜体、下線、取り消し線、見出しレベル。
- **時刻・場所・写真の挿入。** キーボードの上に出るバーからワンタッチで。
- 挿入したものは本文の一部です。飾りではなく、テキストに残る内容です。

### 日記帳

- 年ごと、場所ごと、あるいは好きなように分類できます。
- サイドバーの上半分は**現在の日記帳の目次**、下半分は**日記帳の一覧**です。

### よく使う 4 つ

編集画面の右上のボタンでドロワーが開きます：

| | |
|---|---|
| **コピー** | 本文のみ、またはタイトル＋本文＋作成日時 |
| **検索** | この記事／この日記帳／すべての日記帳から |
| **書き出し** | TXT、Markdown、1 枚の長い画像、分割した複数枚 |
| **時刻** | この記事の作成日時を変更 |

### バックアップ

- フォルダを指定すると、すべての日記と画像を `.mjb` としてまとめます。
- バックアップは**コールドスタート後**と**アプリを離れるとき**に自動で実行され、手動でも実行できます。
- アーカイブはいつでも読み戻せます。上書きする前に中身が確認できます。

> **データはあなたの手元に。** ネットワークを使わず、送信もせず、サーバーもアカウントもありません。

## ダウンロード

[Releases](https://github.com/OutoriNemuri/moment-journal/releases) から最新の `.apk` を入手してください。

- Android 9 以上が必要です。
- ストアには出していないため、インストールには「提供元不明のアプリ」の許可が必要です。

## よくある質問

**バックアップ先はなぜ必須なのですか？**
バックアップ先を決めないと、日記は 1 台の端末に 1 部だけしか存在しません。バックアップは指定したフォルダに**複製するだけ**で、元のデータは端末に残り、どこにも送信されません。

**機種変更で日記は失われますか？**
失われません。`.mjb` を新しい端末にコピーし、「設定 → バックアップ → アーカイブから復元」で読み込んでください。

**クラウド同期はないのですか？**
クラウド同期（WebDAV / オンラインストレージ / FTP）は計画中です。今はバックアップ先をクラウドアプリが同期しているフォルダにすれば、近いことができます。

**日記はどこに保存されますか？**
アプリ専用領域の SQLite データベースです。バックアップは `.mjb`（ZIP）で、データベースのスナップショットとすべての画像が入っています。

## 開発状況

**ベータ版です。** 現在 `0.3 (1)` で、まだ変化が速く、画面や挙動が変わることがあります。

実装済み：日記の編集、日記帳、時刻・場所・写真の挿入、Markdown の書式、検索、コピー、書き出し（TXT / Markdown / 長い画像 / 各種分割）、作成日時の変更、ローカルバックアップと復元、テーマ（壁紙からの動的配色と内蔵配色）。

未実装：小記（1 日に複数書いて 1 記事に統合）、タイムラインとカレンダー表示、気分と天気、クラウドバックアップ、カスタムフォントと編集画面の背景。

進捗は [FEATURES.md](FEATURES.md)、各版の変更は [CHANGELOG](docs/CHANGELOG.md) を参照してください。

## 開発に参加する

Issue での報告や提案を歓迎します。

自分でビルドする場合：

```bash
./gradlew assembleDebug      # 出力: app/build/outputs/apk/debug/
./gradlew testDebugUnitTest  # 単体テスト
python3 tools/preflight.py   # 静的チェック（JDK 不要）
```

ビルドとテストは GitHub Actions で自動実行されます。
