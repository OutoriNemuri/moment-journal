# 时刻日记

**一个流畅的日记软件，记录每一天的日常。**

## 它是什么样的

时刻日记把「记日记」这件事做得尽量不打扰你：

- **写的时候没有负担。** 打开就是编辑器，没有多余的中间页面。
- **写完不用担心丢。** 每改动一停就自动保存，退出时也会再存一次。
- **数据始终在你手里。** 日记只存在你自己的设备上，备份也存进你自己选的文件夹。

## 功能

### 写日记

- **标题与正文**，正文支持 Markdown：粗体、斜体、下划线、删除线、标题层级。
- **插入时间点、地点与图片**，随键盘上方的快捷栏一键插入。
- 插入的内容会真实地嵌在正文里 —— 它们不是装饰，是日记的一部分。

### 日记本

- 按年份、地区或任何你想要的方式分类。
- 侧栏上半部分是**当前日记本的目录**，下半部分是**日记本列表**。

### 随手可用的四件事

编辑器右上角的按钮打开抽屉，里面是：

| | |
|---|---|
| **复制** | 复制正文，或标题＋正文＋创建时间 |
| **查找** | 在本篇、本日记本或所有日记本中搜索 |
| **导出** | TXT、Markdown、一张长图，或切分的几张短图 |
| **时间** | 修改这篇日记的创建时间 |

### 备份

- 指定一个文件夹，时刻日记会把全部日记与图片打包成 `.mjb` 备份进去。
- 备份在**冷启动后**与**切到后台时**自动进行，也可以手动触发。
- 归档随时可以导入回来，导入前会先显示里面有什么。

> **你的数据只在你手里。** 时刻日记不联网、不上传，没有服务器，也没有账号。

## 下载与安装

从 [Releases](https://github.com/OutoriNemuri/moment-journal/releases) 下载最新的 `.apk` 并安装。

- 支持 Android 9 及以上。
- 应用未上架任何商店，安装时需要允许「安装未知来源应用」。

## 常见问题

**备份为什么是必填的？**
时刻日记需要知道把备份放在哪里，否则你的日记只有一份、且只在这台设备上。备份只是**复制一份**到你指定的文件夹，原数据仍在本机，不会上传到任何地方。

**换了手机会丢日记吗？**
不会。把旧的 `.mjb` 归档拷到新手机，在「设置 → 备份 → 从归档恢复」里导入即可。

**为什么没有云同步？**
云同步（WebDAV / 网盘 / FTP）在计划中。目前你可以把备份文件夹设在一个已经被网盘同步的目录里，效果类似。

**日记存在哪？**
应用私有目录下的 SQLite 数据库。备份归档是 `.mjb` 格式（一个 ZIP），里面是数据库快照和全部图片。

## 开发状态

**Beta。** 当前版本 `0.3 (1)`，仍在快速迭代，界面与行为可能变动。

已经做了：日记编辑、日记本、插入时间/地点/图片、Markdown 样式、查找、复制、导出（TXT / Markdown / 长图 / 多种切分方式）、修改时间、本地备份与恢复、主题（动态取色与内置配色）。

还没做：小记（一天多条合并成一篇）、时间轴与日历预览、心情与天气、云备份、自定义字体与编辑器背景。

进度与计划详见 [功能清单](FEATURES.md)；每个版本改了什么见 [更新日志](docs/CHANGELOG.md)。
