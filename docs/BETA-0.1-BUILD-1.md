# 时刻日记 — Beta 0.1 Build 1 范围定义

> 名称：时刻日记 / Moment Journal / 瞬間ジャーナル
> 包名：`com.nemuri.journal`
> minSdk 28 (Android 9) / targetSdk 35 (Android 15)
> 版本：`0.1 (1)` Beta
> 状态：范围冻结，待实现

---

## 一、本版目标

用最小闭环回答一个问题：**这个应用能不能流畅地用来写日记，并且写下的东西不会丢。**

因此 0.1 只做三件事：**录、存、备**。

---

## 二、必做（P0 / P1）

### 1. 数据层

- **SQLite**（Room），WAL 模式。
- `Entry`：`id` / `bookId` / `title` / `body`(Markdown 源文本) / `createdAt` / `updatedAt`。
- `Book`：`id` / `name` / `createdAt` / `sortOrder`。
- `bookId` 从初版 schema 起就必须存在（后补要做数据迁移）。
- 图片**不入库**：正文只存相对路径，文件落在应用私有目录 `files/images/`。

### 2. 富文本与嵌入：隐式扩展 Markdown

正文以 Markdown 源文本为唯一真相，扩展三类内联标记：

| 语义 | 语法 |
|---|---|
| 时间点 | `![time](2026-10-10T20:00:00+08:00)` |
| 地点 | `![loc](lat,lon,名称)` |
| 图片 | `![img](images/uuid.jpg)` |

- 0.1 只解析这三类 + 基础 Markdown（粗体/斜体/下划线/删除线/标题/列表）。
- **时间与图片本版实现，地点留 0.2**（需要权限与地理编码）。
- 渲染器必须支持**源文本 ↔ 样式化视图双向**，否则光标进不去。

### 3. 即刻保存

- 编辑即写库，输入防抖 300–500ms，禁止逐按键 UPDATE。
- 无"是否保存"对话框；冷启动读到的是草稿态。

### 4. 界面

- `日记`：标题 + 正文编辑，展示创建时间。
- `日记列表`：按时间倒序，含标题、摘要、创建时间；点击进入、长按删除。
- `日记本`：侧栏（主界面左侧栏）底部"日记本"区域拉出抽屉，支持新建 / 打开 / 删除。
- `主题`：MD3 基础主题，浅色 / 深色。
- `光标`：闪烁光标（呼吸式顺滑光标留 P3）。
- `软键盘接口`：适配 Android 11+，键盘上方悬浮快捷输入栏承载时间 / 图片插入。

### 5. 本地备份（`.mjb`）

- `.mjb` = ZIP 归档，内含 `journal.db`（经 `VACUUM INTO` 一致性快照）+ `images/` + `manifest.json`。
- `manifest.json` 必带 `version` 字段 —— 格式是长期契约，云备份与恢复都基于它。
- 输出路径：`%i/MomentJournal/Backups`，用户通过系统文件框架指定 `%i`。
- 触发时机：**冷启动完成后** + **应用退到后台 / onStop**（定时改为"变更后 5 分钟且应用处于前台"）。
- **本版必须实现恢复逻辑**，否则归档读不回来。

## 三、明确不做（外推到后续版本）

| 功能 | 版本 |
|---|---|
| 地点插入 | 0.2 |
| 云备份（WebDAV / FTP / SMB） | 0.2+ |
| 编辑器背景自定义 | 0.3 |
| 全局字体（CEF Fonts CJK / 系统 / .ttf/.otf） | 0.3 |
| 呼吸式顺滑光标、静态光标选项 | 0.3 |
| MD3 Expressive | 待上游稳定 |

`云备份会直接复用 0.1 定义的 .mjb 格式，因此本版必须先把格式验证充分。`

---

## 四、验收标准

- [ ] 冷启动 → 新建日记 → 输入文字 → 杀进程 → 重开，内容完整保留。
- [ ] 连续输入 2000 字不卡顿，数据库无逐键写入。
- [ ] 插入时间戳与图片后，正文源文本可读、可再编辑。
- [ ] 新建 / 切换 / 删除日记本，列表过滤正确。
- [ ] 备份产出可被重新导入，条目数、正文、图片与备份前一致。
- [ ] 深色 / 浅色主题切换无残留。

---

## 五、已知风险

1. **`.mjb` 格式即长期契约**：`version` 与恢复逻辑必须在 0.1 内闭环。
2. **定时备份的承诺**：Android Doze 与后台限制会压制精确周期任务，故本版不做 5 分钟精确定时。
3. **SQLite 快照一致性**：不得直接复制正在写入的数据库文件。
