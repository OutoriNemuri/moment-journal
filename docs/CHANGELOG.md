# 更新日志

本项目尚在 Beta 阶段。版本号形如 `<次版本> (N)`，`N` 为 Build 序号；
每个 Build 只要产出了可安装的 APK 就会记入本文件。

> **关于版本号曾经停滞的说明**
>
> `0.1 (2)` 这一条同时包含两批改动：应用图标（原定的 Build 2 范围），
> 以及随后并入的 0.2 前期改动（日记本改为容器、接通备份）。
> 也就是说，**0.2 的部分内容曾经顶着 `0.1 (2)` 的版本号发布过**。
>
> 这一点不做追溯修改，因为已经构建出的 APK 上写着 `0.1 (2)`，改了就对不上。
> 自 `0.2 (1)` 起版本号恢复正常递进。

## 0.2 (1)

**主题：让已经写好的东西真正可用，并补齐基本功能。**

### 修复

- **应用图标不可见**。自适应图标的背景色曾被定义为近白色 `#FBFDF8`，
  而前景字形是纯白 `#FFFFFF`，两者对比度仅 1.02:1，等于白底白图。
  背景改为蓝色 `#1B4F9C`，对比度 7.94:1。
- **图标两条路径配色不一致**。低版本用的 PNG 回退图是绿色 `#4A6350`，
  与高版本自适应图标的背景色不同。现在两者统一由
  `tools/build_icons.py` 的 `BRAND_BG` 与 `res/values/colors.xml` 共同决定。

### 新增：基本功能

编辑界面右上角新增一个按钮，打开下侧抽屉，四项功能集中在此。

- **复制日记**。可选「仅正文」或「标题 + 正文 + 创建时间」。
  输出的是 **Markdown 源文本**而非渲染后的纯文本 —— 正文本身即 Markdown，
  插入的时间、地点、图片都是文本形式；复制成纯文本会丢掉全部样式与嵌入
  且无法还原，而 Markdown 粘回本应用任意一篇日记都能还原。
- **查找**。三档范围：本篇日记 / 本日记本 / 所有日记本。
  跨日记本查找是**一次性的结果列表**，关闭即结束，不改变当前打开的日记本。
- **导出**。四种目标：TXT（嵌入转为可读文字）、Markdown（保留全部标记）、
  一张长图、切分的几张短图。
- **时间**。修改创建时间。日记按创建时间排序，改后位置会变化，
  界面上有提示说明，否则会被误认为数据丢失。

### 变更

- 版本号由 `0.1 (2)` 提升至 `0.2 (1)`。

### 说明

见下方 `0.1 (2)` 条目中「并入的 0.2 前期改动」一节：日记本改为容器、
备份功能首次真正可用、数据库迁移 1 → 2。

### 不在本版

- `小记`。需要新的数据模型（当天草稿 → 日终合并），且企划写明合并后
  原始小记会被删除 —— 属于不可逆操作，而 `.mjb` 恢复流程至今未经验证，
  在没有退路时不执行不可逆操作。
- 时间轴 / 日历预览、心情与天气。
- Alpha 功能（Pro、AI Copilot）。见 [FEATURES.md](../FEATURES.md)：
  它们卡在决策而非开发。
- 多语言支持。已提上日程，但尚未实施；目前字符串仍硬编码在 Kotlin 中。

## 0.1 (2) — Build 2

**主题：应用图标。**

### 新增

- **应用图标**。采用 Material Symbols 的 `book` 字形，由 `tools/build_icons.py`
  从官方矢量字形自动生成，而不是手工描摹：
  - **API 26+**：使用自适应图标（`mipmap-anydpi-v26/`），前景为透明底图形，
    背景为品牌绿，交给系统按各厂形状（圆形 / 方形 / 圆角矩形）裁切；
    同时声明 monochrome 层，以支持 Android 13+ 的主题图标。
  - **API 25 及以下**：不支持自适应图标，回退到 `mipmap-*/` 下的 PNG
    （mdpi 至 xxxhdpi 五档密度）。高低两版图形出自同一字形，观感一致。
- `tools/preflight.py`：接入 CI 的静态预检。

### 变更

- 移除了占位的矢量前景 `drawable/ic_launcher_foreground.xml`（已无引用）。
- 补齐 `ic_launcher_round.xml`，使其与 `ic_launcher.xml` 的定义一致
  （此前它仍指向被移除的旧矢量图，且缺少 monochrome 层）。

### 说明

- 图标资源全部由脚本生成，需要改图形时改脚本重跑，不要逐像素编辑 PNG。

### 并入的 0.2 前期改动

以下内容原属 0.2 范围，因体积不大且互相独立，随本 Build 一并交付。

**日记本改为容器**

- 主界面只显示当前打开的日记本中的日记；侧栏上半段改为该本的目录，
  原先的「全部日记」入口取消。日记本不再是分类标签，而是容器。
- 没有当前日记本时**不能新建日记**，新建按钮在该状态下不出现，
  而不是仅改变颜色后点击无反应。
- 当前日记本会记住，重启后自动回到上次打开的那一本。若记住的那本已被删除，
  退回到最早创建的一本；一本都没有则自动创建一个。

**备份功能首次真正可用**

- 此前 `BackupScheduler.setBackupTreeUri` 没有任何调用者，文件访问授权从未申请过，
  三个备份触发点全部空转 —— **备份在之前的版本中一次都没有真正执行**。
- 新增首次启动引导：要求指定备份目录，选定后立即执行一次备份，让结果当场可见。
  选择「稍后再说」也可，但主界面会常驻一条提示说明日记仅存本机。
- 新增备份设置页：查看当前位置与上次结果、手动备份、从归档恢复。
  恢复前会先展示归档内容并要求确认。
- 补上了授权持久化（`takePersistableUriPermission`）。缺少它时授权会随进程消失，
  重启后备份悄悄失效而界面看起来一切正常。

**数据库迁移 1 → 2（非破坏）**

- 确保至少存在一个日记本，并把没有归属的日记回填到该本。可重复执行。
- 外键仍为 `SET NULL`；非空约束与级联删除推迟到后续版本。因此本版删除日记本时，
  会先把其中的日记移入其他本再删除，避免产生在界面上再也找不到的孤儿日记。

## 0.1 (1) — Build 1

第一个可安装版本。目标是回答一个问题：**这个应用能不能流畅地用来写日记，
并且写下的东西不会丢。** 因此只做三件事：录、存、备。

### 新增

**录**

- 日记编辑器：标题 + 正文，展示创建时间。
- 日记列表：按时间倒序，显示标题、摘要与创建时间；点击进入，长按删除。
- 日记本：主界面左侧抽屉底部区域，可新建 / 打开 / 删除；删除日记本时
  其中的日记退回「未分类」，不会被连带删除。
- Material 3 浅色 / 深色主题；闪烁光标；适配 Android 11+ 软键盘接口，
  快捷输入栏随键盘上浮。

**存**

- 正文以**隐式扩展 Markdown 源文本**为唯一真相，编辑器直接编辑源文本，
  因此光标永远进得去。三类内联嵌入：

  | 语义 | 语法 |
  |---|---|
  | 时间点 | `![time](2026-10-10T20:00:00+08:00)` |
  | 地点 | `![loc](31.2304,121.4737,上海)` |
  | 图片 | `![img](images/3f2a1b.jpg)` |

  无法识别的标记一律降级为普通文本，绝不抛异常、绝不丢数据。
- 图片不入库：正文只存相对路径，字节落在应用私有目录。
- SQLite（Room）+ WAL。输入防抖 400 ms 后落库，退出编辑或切后台时强制写盘。
- 编辑器支持「预览」模式，可查看渲染后的样式与嵌入内容。

**备**

- 本地备份，归档格式 `.mjb`（ZIP）：

  ```
  journal.mjb
  ├── manifest.json   含 formatVersion、条目数、图片数
  ├── journal.db      一致性快照（VACUUM INTO 产出）
  └── images/         正文引用的全部图片
  ```

- 恢复流程为「先全量校验、后破坏性替换」：校验不通过时，现有数据完全没有
  被触碰。归档版本高于本应用支持的版本时拒绝读取，而不是猜着解析。
- 触发时机：冷启动完成后、应用退到后台，另有 WorkManager 15 分钟下限兜底。

### 已知限制

- **地点插入未实现**（需要权限与地理编码），计划 0.2。
- **云备份未实现**，计划 0.2 及以后。
- **不做 5 分钟精确定时备份**：Android 的 Doze 与后台限制会压制周期任务，
  承诺一个做不到的周期，只会让用户误以为数据安全。
- 编辑器背景、全局字体、呼吸式光标、MD3 Expressive 均未实现，计划 0.3 及以后。

## 构建与验证

iSH 环境没有 JDK 与 Android SDK，因此全部编译与测试在 GitHub Actions 完成。
`tools/preflight.py` 覆盖本地可查的部分（Kotlin DSL 语法、wrapper 完整性、
依赖与 import 对照、资源引用、YAML），并排在 Gradle 之前执行，
用于在昂贵的构建启动前失败。
